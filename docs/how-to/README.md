# How-to Guides

Use these guides when you already understand the basic redirect workflow and need
to complete a specific operational task:

- [Configure the JSON source](configure-json-source.md) — create, validate, and
  replace redirect definitions safely.
- [Configure JSONL events](configure-jsonl-events.md) — choose a writable output,
  inspect events, and plan collection or rotation.
- [Deploy with Docker](deploy-with-docker.md) — run the non-root production image
  with persistent event storage.
- [Run behind a reverse proxy](reverse-proxy.md) — reconstruct public HTTPS URLs
  without trusting client-supplied forwarding metadata.
- [Prepare for production](prepare-for-production.md) — verify ownership,
  security, persistence, health, and change procedures before adoption.
- [Publish a tagged container release](publish-container-release.md) — maintain
  the release summary and publish an immutable multi-platform image.
