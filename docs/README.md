# Compactor Documentation

Start with the outcome you need:

- **Learn the workflow:** [Tutorials](tutorials/README.md) take you from a clean
  checkout to a working redirect and event.
- **Complete an operational task:** [How-to guides](how-to/README.md) cover
  configuration, deployment, proxies, events, releases, and production readiness.
- **Check an exact contract:** [Reference](reference/README.md) defines every
  environment value, JSON field, event field, adapter result, and URL rule.
- **Understand a design choice:** [Explanation](explanation/README.md) describes
  the boundaries that keep Compactor small and predictable.

New adopters should run [Getting started](tutorials/getting-started.md), then use
the [production readiness guide](how-to/prepare-for-production.md) before placing
Compactor on a public request path.

For contributor-level component ownership and data flow, see the maintained root
[architecture document](../ARCHITECTURE.md).
