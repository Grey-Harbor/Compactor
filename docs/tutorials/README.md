# Tutorials

Tutorials teach Compactor through complete, working paths. Follow them in order
when evaluating the service for the first time.

- [Getting started](getting-started.md) — run one redirect and inspect its event.
- [Build Compactor from source](building-from-source.md) — compile the service,
  run its verification suite, and preview the GitHub Pages export.
- [Run Compactor with HTTP adapters](http-adapters.md) — exercise remote source
  lookup and event delivery with the bundled mock service.

After the tutorials, use the
[production readiness guide](../how-to/prepare-for-production.md) to turn the
local example into an operational deployment plan.
